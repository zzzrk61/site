API Documentation

📍 Base URL

https://api.voidtrace.io

L'API VoidTrace fournit un accès rapide aux données Discord et IP. Authentification par clé API.

🔐 Authentification

Authorization: Bearer YOUR_API_KEY

Tous les appels API requièrent une clé valide passée en en-tête Authorization. Obtenez votre clé dans le Dashboard admin.

📤 POST /api/search

POST /api/search

Recherche multi-critères. Retourne les données Discord et IP en JSON structuré.

Body (JSON):

{ "discord_id": "123456789012345678", "ip": "192.168.1.1" }

Response:

{ "data": { "discord": { userInfo, breach, fivem, score, meta }, "ip": { query, country, city, isp, org, lat, lon } } }

🔍 GET /api/lookup/discord/:id

GET /api/lookup/discord/803511102246789120

Lookup détaillé d'un Discord ID. Retourne profil, breaches, FiveM records, sanctions DSA.

🌍 GET /api/lookup/ip/:ip

GET /api/lookup/ip/192.168.1.1

Lookup d'une adresse IP. Retourne géolocalisation, ISP, organisation, coordonnées.

⚡ Rate Limits

Free Plan: 60 requêtes/heure

Pro Plan: 1000 requêtes/heure

Unlimited: Pas de limite

Les rate limits sont retournés dans les en-têtes: X-RateLimit-Remaining, X-RateLimit-Reset

❌ Codes d'erreur

400 - Requête invalide

401 - Clé API manquante ou invalide

404 - Utilisateur non trouvé

429 - Rate limit dépassé

500 - Erreur serveur
