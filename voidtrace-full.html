Introduction

L'API VoidTrace expose trois modules : lookup de profils Discord par Snowflake ID, géolocalisation d'adresses IP, et recherche par nom/prénom. Accessible via HTTP GET avec authentification par clé API.

Base URL :

https://api.voidtrace.io/v1

Authentification

Toutes les requêtes nécessitent votre clé API dans le header :

X-VT-Key: vt_your_api_key_here
Ne partagez jamais votre clé API. En cas de compromission, régénérez-la depuis votre dashboard.

Discord Lookup

GET/discord/{snowflake_id}
# Exemple curl -X GET "https://api.voidtrace.io/v1/discord/803511102246789120" \ -H "X-VT-Key: vt_your_key"

IP Lookup

GET/ip/{address}
# Exemple curl -X GET "https://api.voidtrace.io/v1/ip/1.1.1.1" \ -H "X-VT-Key: vt_your_key"
Les données de géolocalisation sont indicatives. VoidTrace ne garantit pas la précision à l'échelle d'une adresse physique.

Info Lookup

Recherche par nom et prénom via l'API BrixHub. Nécessite la permission info.

GET/api/brix/{prenom}+{nom}
# Exemple curl -X GET "https://api.voidtrace.io/api/brix/Jean+Dupont" \ -H "X-VT-Key: vt_your_key"
La permission Info doit être activée par un administrateur pour accéder à cet endpoint.

Mentions légales & CGU

Dernière mise à jour : juin 2025 · VoidTrace Platform

1. Éditeur du service

VoidTrace est une plateforme OSINT proposant des services de lookup de données publiques, accessible à voidtrace.io.

2. Nature des données traitées

VoidTrace traite exclusivement des données publiquement accessibles :

  • Profils Discord publics via l'API officielle Discord
  • Informations de géolocalisation IP issues de bases WHOIS et GeoIP publiques
  • Données de recherche par identité issues de l'API BrixHub

3. Utilisations autorisées

  • Sécurité informatique défensive (audit, investigation)
  • Vérification d'identité dans un cadre légal
  • Recherche académique et journalisme d'investigation
  • Modération de plateformes

4. Utilisations interdites

  • Harceler, traquer ou cibler des individus
  • Collecter des données pour les revendre sans accord
  • Contourner des mesures de sécurité ou violer des CGU tierces
  • Toute activité illégale (RGPD, GDPR, lois locales)
  • Surveillance non consentie de personnes physiques

5. Conformité RGPD

  • VoidTrace ne stocke pas les requêtes ni résultats de lookup
  • Aucun cookie de tracking tiers
  • Logs techniques conservés 30 jours maximum
  • Droit à la suppression des données sur simple demande email

6. Limitation de responsabilité

VoidTrace fournit un accès à des données publiques à titre informatif. L'exactitude n'est pas garantie. La responsabilité de l'usage final incombe entièrement à l'utilisateur.
