Infos API BrixHub

La documentation de l'API BrixHub vous permet d'interroger nos bases de données publiques pour obtenir des informations sur des identités, IP, etc. Utilisez votre clé API pour authentifier chaque requête.

Base URL

https://api.brixhub.ch/api/v1

Authentification

Incluez l'en-tête X-API-Key avec votre clé API dans chaque requête.

Exemple de requête GET

curl -X GET "https://api.brixhub.ch/api/v1/endpoint" \n -H "X-API-Key: votre_clé_api"

Réponse typique

{
  "status": 200,
  "data": { ... }
}

Consultez la documentation complète dans votre espace développeur pour plus de détails.
